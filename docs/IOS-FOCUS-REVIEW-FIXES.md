## 第二轮体验与实时活动

- 当前空格直接提供「添加并开始」，减少寻找工具栏入口的成本。
- 创建 sheet 先展示标题、落点和提交；图标、估算、常用收进「更多」。顶部入口默认立即开始，工具栏默认安排；使用带值的 sheet 状态，修复首次打开仍误用旧默认值的问题。
- 下一步按真实会话阶段生成。长休期间不再提示「接下来再长休」；格内专注使用之后的实际短休 / 长休种类，即使当天此前没跑满三轮也保持与计划一致。
- 停止休息使用休息专属确认文案，覆盖全部 19 个 UI locale。
- 专注 / 休息进度改为系统 `ProgressView(timerInterval:)`，扩展休眠时仍可更新；展开态阶段说明替代冻结的百分比。
- 修复普通下班活动误走专注单段进度的判断；普通班次继续使用完整有效 segments。
- 模板编辑器补充「设为休息」，沿用已有翻译；工作格可以转成休息，保存后重新打开与应用均保留。
- 运行中的标题直接显示任务名，省去重复阶段前缀；最大辅助字号支持三行。
- 时间带定位目标使用实际布局位置；辅助字号列表同样提供格子 ID。已实测格子分配后回到相应位置，普通时间带与辅助字号列表均可继续编辑。

# 3.1.9 商店名称与关键词建议

日期：2026-09-08。用户已确认采用下方关键词方案。17 种语言关键词已写入本地 3.1.9 配置，并通过项目 ASC API 更新至 iOS 3.1.9 草稿；名称和副标题保持不变。

## 建议

- 保留现有 17 个本地化名称：DoneAt + 当地语言的下班倒计时。新功能扩展了用途，但没有替代最清楚的入门需求。
- 本次保留副标题。App Info 与 macOS Universal Purchase 商品页共用；记录、人生、专注目前是 iOS 功能，不宜把这些写成两端共同的承诺。
- 调整 iOS 版本级关键词：保留下班、加班、工资、午休等相关词，腾出位置给专注、任务、工时记录。中文补番茄钟、待办、人生；英语补 focus、tasks、time tracking、pomodoro。
- 不加入 Apple Watch、AI、团队考勤、自动记账等尚未提供的能力。不把收入估算包装成投资、理财或薪资管理。

## 判断依据与限制

这些是基于现有功能与自然语言的相关性建议，不是搜索量或转化率实验结果；没有使用搜索量工具，也没有排名提升承诺。发布后应对照 App Store Search 来源的曝光、商品页转化及下载，判断新词是否有效。各语言最终上架前仍适合由母语用户复核搜索习惯。

Apple 的搜索说明要求关键词准确、避免重复名称/副标题和泛词；推广文本不影响搜索排名。官方营销说明写 100 characters，Connect 字段参考写 100 bytes，本建议同时满足 Unicode 字符数和 UTF-8 字节数不超过 100，以免多字节语言踩线。

- [Apple：App Store search](https://developer.apple.com/app-store/search/)
- [Apple：Platform version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information)

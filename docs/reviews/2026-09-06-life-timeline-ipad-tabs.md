# 工作经历与 iPad 界面补充验收

## 实现范围

- 详细经历从当前工作向前填写。当前结束展示“现在”、保存开放结束值，往期结束自动衔接下一份工作的开始日期；编辑/删除自动重连。旧经历保留标识与薪资，缺少当前工作时推导可编辑起点。粗略模式不改写隐藏的详细经历。
- 日期选择及结束日期显示采用记录时区，避免设备换时区后移动日期。
- 记录与数据采用同层级设置页的大标题和返回导航。
- iPad 顶部侧边栏按钮采用标签内 44×44 pt 命中区域，独立于三个 Tab 的拖动区域。Tab 选中胶囊采用原生玻璃效果，拖动位置连续更新并限制在轨道内，松手按现有动效吸附；支持从右向左布局和减弱动态效果。
- 默认专注任务、专注入口、介绍与历史卡使用秒表；计时 Tab 保留倒计时图标。

## 验证

共享测试 357 项通过，Swift Testing 418 项通过；lint、版本一致性、iOS 配置检查及原生规则再生成通过。Web 构建和 Desktop 导出及对应验证通过。补充日期显示时区后最终 iOS build 通过；连续拖动玻璃 Tab 最终 build 也通过。

实际交互验收在模拟器进行：iPad 验证计时拖至设置、向左越界限制到计时且不触发侧边栏、普通点按记录。记录与数据和班次设置标题层级一致；侧边栏入口及专注秒表图标确认。Pro Max 验证详细经历显示当前至现在，以及两段往期的自动结束日期；Save 已可用，但保存/重开的 UI 验证未完成：CUA 对模拟器 sheet 顶部按钮的坐标点击持续返回 windowNotFoundAtPosition，刷新窗口与显示器定位后仍失败。日期衔接及持久化数据结构由 Swift 回归测试覆盖，不将工具失败判为应用保存失败。

# 2026-09-19 节假日与调休模板验收

用户在 Watch/P8 PR #207 合并后明确选择开始节假日模板。本轮实现 018 的该项功能，不表示整个 018、019 或发布门禁完成，不上传或发布。

## 实现与边界

- 排班月历下方提供模板选择、搜索、切换和关闭；第一次选择时建议系统地区。旧数据不自动改变排班，选择先进入草稿，统一保存后生效。
- 人工逐日指定与历史冻结班次优先于模板，模板优先于周期和月份沿用。调休上班日保留原工作班；原为休息时采用首个未归档工作班次，无工作班次时不虚构时间。
- 月历区分节假日和调休上班日，所选日期显示完整名称；排班页与“接下来”提示缺少年份和年底下一年缺口。未知年份使用普通排班。
- 模板地区作为扩展排班内容的可选字段保存，进入快照、备份及现有 CloudKit DTO；旧数据缺失字段仍可读。不批量生成重复的 CalendarException 行，模板来源由共享解析器标记。
- Watch 使用同一 Swift 解析器。协议 V3 携带手机所选地区的具体日期效果，不复制全球名称库、不发送薪资。V1/V2 缓存继续可读；同配对世代拒绝协议降级。新能力要求两端升级。
- 升级欢迎页加入节假日与调休说明，明确需到“工作时间与排班”选择地区手动开启；19 语言齐全，沿用 3.2.0 一次性升级提示，新安装不重复展示升级页。
- App 关于页和官网中英文关于页包含来源与完整 MIT 许可。官网修改位于独立 doneat-site 工作区，尚未部署。

## 数据证据

- Vacanza holidays 0.83 固定 wheel；holiday-cn 固定提交 `18c8f140cd8574faf72c8bb5cd0a9bdf9d1c1b6c`。来源和许可证哈希见 `scripts/holiday-template-sources.json`。
- 249 个全国级地区，2513 条名称表，55478 条日期记录，19 个 App 语言名称及英文／来源语言兜底。无下级行政区数据。
- JSON 为 2,660,387 字节，低于 5 MB 上限。SHA256：`e5cff08060595995422c4c13572c70676ff39968a0e7530d4a5c389d2fd62501`。
- 非中国大陆为上游规则生成的 2020–2035 年公共假日，不能将未来计算结果称为已获政府公告确认。中国大陆按公告覆盖 2007–2026 年；2027 年空文件不产生猜测安排。
- 审查修正：Vacanza WORKDAY 类别包含普通工作日的纪念日，不可作为强制上班。因此全球只采用 PUBLIC 类别；131 条调休上班记录全部来自中国大陆明确公告。离线检查覆盖芬兰五一、母亲节与台湾元旦回归。
- 构建仅读取已提交 JSON，不依赖 Python、PyPI 或运行时网络。固定来源重新生成的结果逐字节一致，离线检查已接入测试与 Xcode Cloud 前置检查。

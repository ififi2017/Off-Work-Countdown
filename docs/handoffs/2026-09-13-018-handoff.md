## 4. 当前必须先修的编译错误

最新编译日志：`/private/tmp/owc-ios-018-watch-producer-build-tests-second.log`。

`WatchSnapshotPublisher.swift:349` 的 WCSessionDelegate replyHandler：

1. 原签名 `@escaping (Data) -> Void` 在 Task 转 MainActor 时报告 `sending 'replyHandler' risks causing data races`。
2. 主代理最后尝试给参数加 `@Sendable`，最新构建明确失败：`sendability of function types ... does not match requirement in protocol 'WCSessionDelegate'`。
3. **这份不匹配的 @Sendable 参数仍在工作树里，暂停时没有继续修。** 本机 WCSession.h 的 ObjC block 没有 Sendable 标记，不能把 WidgetKit 已标注 Sendable 的方案机械搬来。

下一位应读 Swift 并发 skill，设计局限于这个 legacy callback 的安全转交／一次性消费边界，保留 epoch／nonce 检查。不要直接把整个类标 unchecked Sendable 或用全局关闭严格并发掩盖问题；如果必须使用窄范围桥接，说明所有权与并发依据并补测。修完还可能出现后续测试编译错误，需继续完整编译。

Watch Widget TimelineProvider 曾同样报 sending completion，但该 SDK 正式签名确为 `@Sendable`；已按 SDK 补齐，并通过该段编译，后续只卡 asset runtime。

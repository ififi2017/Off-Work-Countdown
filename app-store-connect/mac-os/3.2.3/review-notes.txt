1. DEVICES AND OS TESTED

MacBook Pro (MacBookPro18,3, Apple M1 Pro), macOS 27.0. The build is a universal binary (arm64 + x86_64).

2. PURPOSE AND TARGET AUDIENCE

DoneAt, formerly known as Off Work Countdown, is a countdown timer for the working day. The user sets a start time, end time and working days once; the app shows how much of the shift is left, how far along the day is, and optionally how much they have earned so far, updating every second.

The countdown appears in the main window, the menu bar, a floating mini timer and a desktop widget.

Target audience: office and shift workers, including overnight shifts that cross midnight. Localised into 19 languages. No account, no sign-up, no server; all settings and state stay on the user's Mac.

3. SETUP AND ACCESSING MAIN FEATURES

No account, credentials or sample files are required. The app is fully functional on first launch.

1) Launch the app.
2) Set a start and end time. To see the countdown immediately, set an end time a few minutes ahead.
3) Optionally select which weekdays are working days.
4) Press "Start countdown".
5) The countdown then appears in the main window, the menu bar, and the floating mini timer (toggled from the title-bar button).
6) Widgets: open Notification Center or right-click the desktop, choose "Edit Widgets" and find "DoneAt". There are five styles: the original countdown (two sizes), Big digits, Ring, Today's timeline and Detail. Placing a widget on the desktop requires macOS 14 or later; on macOS 13 they are available in Notification Center only.

New in 3.2.3:
- Four new widget styles. Big digits shows the time left; Ring and Today's timeline split the day at the lunch break; Detail lists what's coming up (lunch, clock-off, the next shift). They read the same salary-free snapshot as the existing widget and never show earnings.
- Holiday calendar: mainland China now includes 2027, marked in the app as predicted until the official arrangement is published.
- The schedule calendar shows make-up workdays as workdays.

Optional features are in Settings (title-bar button): salary display, lunch break, notifications, launch at login, and a global show/hide shortcut.

4. EXTERNAL SERVICES, TOOLS AND PLATFORMS

None. The app has no backend and makes no network requests. No analytics, telemetry, crash reporting, accounts or AI services. All computation is done locally from the times the user enters, and all state is stored in a local file inside the app's sandbox container.

The only outbound behaviour is opening a URL in the user's default browser when the user explicitly taps a share button (X, Facebook, WhatsApp, Telegram, LINE, Reddit, Weibo) or a link on the About page. Nothing is sent automatically, and nothing is sent from within the app itself.

The app declares com.apple.security.network.client only because WKWebView spawns helper processes that fail to start under App Sandbox without it. The app itself performs no networking.

5. REGIONAL DIFFERENCES

The app functions identically in all regions. The interface is localised into 19 languages and follows the system language by default; the user can change it in Settings.

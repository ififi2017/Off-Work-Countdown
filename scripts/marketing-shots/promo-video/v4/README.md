# DoneAt · 宣传视频 V4

中文竖屏短片，25 秒，1080×1920、60 fps。前三版的思路是「多讲几个功能」，这一版反过来：整条片子只讲一件事，每个画面、动作和声音都要说得出为什么。

## 简报

| 项 | 这一版的取舍 |
| --- | --- |
| 一个意思 | 别再看几点了，看今天还剩多少 |
| 一种感受 | 心里有数，松一口气 |
| 受众 | 在短视频平台刷到的上班族 |
| 长度与格式 | 25 秒，9:16，两个声音版本 |
| 不讲的东西 | 午休、木鱼、提醒、专注、记录、人生视图，都留给前几版和商店图 |

## 视觉规则

- **三种颜色**：奶油底 `#FFF1D8`、梅子墨 `#2B1935`，橙色只用在 App 的进度条上（取自截图的 `#F2590A`）。最强的颜色只给产品界面。
- **两种字体**：数字用 SF Pro（系统字体），中文用苹方。
- **背景从头到尾不变**，片尾也用奶油底，不切到深色。
- **不用发光、渐变、颗粒、暗角、文字阴影**。要突出某样东西，就靠大小和对比。唯一的阴影是手机下面很轻的一层接地影。
- **字幕只有一个位置、一种样式**：y≈1300，标题 64px，副标题 40px、梅子墨 58%。每个镜头最多一句标题加一句副标题。

## 分镜

96 BPM，一小节 2.5 秒，每个镜头都从小节线开始。

| 时间 | 镜头（一个镜头一个意思） | 字幕 | 声音 |
| --- | --- | --- | --- |
| 0–5.0 | **时间**：奶油底上只有一个大大的「14:22」，镜头缓慢推近 | 又看了一眼时间。/（2.5 秒）可离下班，还有多久？ | Am → F，只有铺底，像一个问题 |
| 5.0–10.0 | **答案**：「14:22」退到左上角变成状态栏，倒计时 02:37:52 一位位升起，进度条填到 62.4% | （7.5 秒）不只是几点，/ 还有今天走了多少。 | 数字到位时轻响 8 下；C → G 拨弦进来，像给出答案 |
| 10.0–15.0 | **是这个 App**：镜头拉远，版式正好落回真实的计时页，机框和界面出现 | DoneAt 下班倒计时 / 把一天，变成一条进度条。 | Am → F，加入轻鼓 |
| 15.0–20.0 | **准点**：硬切到 16:59，00:00:03 → 00:00:00，标签变成「今日已下班」 | （17.9 秒）今天，准点下班。 | 鼓和拨弦停下，只留 G 挂留和弦；每秒一声轻嘀嗒；归零落回 C |
| 20.0–25.0 | **品牌**：走满的进度条收成一道短横线，图标、名字、口号、「App Store 搜索 DoneAt」依次出现，停 4 秒 | — | 一声轻铃，C 和弦余音淡出 |

几处取舍：

- **转场都从上一个画面长出来。** 时钟不是被切走，是自己缩成状态栏；大字版式不是换成截图，是镜头拉远后发现它本来就是 App 的那一屏；片尾的横线就是那条走满的进度条。
- **硬切只用一次**，在 15.0 秒，用来表示「一下午过去了」。切过去以后倒计时严格按真实时间一秒一跳。画面上只要出现读数，就不快进，免得让人以为 App 能让时间变快。
- **节奏有快有慢。** 答案那一下动得快（数字 45 ms 错开、1 秒内到位），然后给 2.5 秒让人读完。归零之后停 2.5 秒，片尾停 4 秒。
- **缓动**：到达用 `cubic-bezier(.22, 1, .36, 1)`（先快后慢），镜头和变形用 `(.65, 0, .35, 1)`。滚动数字照搬 App 的 RollingText。没有线性运动。
- **数字都对得上**：09:00–17:00、午休 12:00–13:00、有效工时 7 小时，和商店截图同一天。14:22:08 时剩 2:37:52、进度 62.4%。16:59:57.5 起剩 3 秒。
- **第三镜是真实截图**：`../../ios/raw/zh-1.png`，只在会动的部分（状态栏时间、倒计时、标签、进度条、气泡）盖一块同色底再重画。对齐已经量过，误差在 1 pt 以内：`--measure` 按 2 px/pt 渲染、不显示截图，逐项和截图的像素框比较。
- **收尾标签**用 App 里的真实文案 `offWorkToday`（今日已下班）。

## 声音

全部由 `audio.mjs` 现场合成，没有素材文件。效果音只有五种，每一种都对着画面上的一个动作：数字到位、进度填充、最后两秒的嘀嗒、归零、品牌出现。实测起音时间 5.30–5.61 / 15.5 / 16.5 / 17.5 / 20.45 秒，和画面同帧。没有房间底噪、打字声和嗖嗖声。

- `doneat-v4-zh-60fps-music.mp4`：效果音加配乐，响度约 -15 LUFS，峰值 -2 dBFS。
- `doneat-v4-zh-60fps.mp4`：只有效果音，峰值 -5 dBFS。大部分时间是静音，所以没有做响度归一（归一会把几声嘀嗒放得很大），是留给平台配乐垫在下面用的。

## 生成

需要本机 Google Chrome、ffmpeg 和 Node 22 以上，不新增 npm 依赖。约 30 秒出片：

```sh
node scripts/marketing-shots/promo-video/v4/render.mjs
```

```sh
node scripts/marketing-shots/promo-video/v4/render.mjs --stills 0,5.5,13,17.6,21
```

`--safe` 叠加安全区；`--align` 把真实截图以 50% 盖在重画上面；`--measure` 见上。浏览器里打开
`scene.html?t=6.5` 看单帧，`?play` 实时播放。时间轴在 `scene.html` 的 `S`，声音事件在
`AUDIO_TIMELINE.cues`，和弦进行在 `audio.mjs` 的 `bars`。

## 已检查

- 按每 0.5 秒一帧从头看到尾；另外逐帧算画面差异：最大的两处是拉远时的最快一段和 15.0 秒的硬切，没有别的跳帧。
- 转场帧逐个看过。第一轮发现三处弱帧，都已修正：时钟缩小时穿过刚出现的倒计时；拉远时半透明的手机像个幽灵；片尾最后一位数字还没淡出，品牌名就叠上来了。
- 所有文字和读数都在 x 64–920、y 190–1500 之内。只有进度条右端伸到 x≈1000，会落进 TikTok 右侧按钮列，但那一段没有文字。第四镜因此不显示气泡。

原版、`../tiktok-v2/`、`../tiktok-v3/` 都没有改动。

**本计划不改变商店价格、不上 IAP。** 通用购买记录**已经是免费下载**。006 才加试用、订阅和付费墙。007 过审后对外上架，不会产生买断用户，006 的「无 iOS 买断迁移」仍成立。

**本计划不写当日覆盖表、观察日志、CloudKit、付费墙。** 提前上班 / 提前下班 / 手动计时 / 「今天也改」写计时页本地标记，语义必须能一对一投影到 002 的 `DayOverride`，但投影本身是 002 P0A 的事。

## 已定口径（面试锁死，细节以 surfaces 文档为准）

计时 Tab 有排班时只在：**上班倒计时 → 下班倒计时（午休 / 加班穿插）→ 结算 → 按结束日次日零点切休息或上班倒计时**。休息日：弱倒数（与上班倒计时同一进度口径）+ 本周 / 本年结算 + 「手动计时」。未排班：每天「手动计时」决定今天有没有班。

- 欢迎页最后一页才是班次表单（时刻 + 固定星期至少一天，或先不排班）。大小周 / 轮班只在设置。老用户不重跑欢迎页。
- 上下班时刻只在排班设置页改。改班次形态必问今天，三项无预选；「今天也改」清掉当天三件修正。
- 提前上班只在上班倒计时：开始=现在，下班时刻不变。不做迟到。
- 提前下班只在下班倒计时；与计划结束都是下班，用户优先。结算没有「返回」。
- 加班可在计划结束前登记；结算再加 = 「其实还没走」。
- 「接下来」只在上班 / 下班倒计时。分享只在上班 / 下班倒计时和结算，文案跟屏幕上的钟；链接只带排班时刻。
- 有排班没有停止倒计时。规则错误用横幅，不停表。
- 不说「强制计时」「武装」。休息日与未排班的主按钮都叫「手动计时」；有排班的休息日进班后用横幅取消，不留「上过班」。

完整形态、壳层、日历缝、分享表见 [docs/IOS-TIMER-SURFACES.md](../docs/IOS-TIMER-SURFACES.md)。

### P1 — 设置与欢迎页接管配置

计时 Tab 不再编辑班次形态。

- 排班设置页顶部可改上下班时刻。
- 改时刻 / 午休 / 工作日 / 排班模式 / 先不排班：选择器合上弹出「只从下一班起 / 今天也改 / 取消」，无预选；取消回滚。「今天也改」清提前上、提前下、加班。
- 固定星期至少一天；最后一天勾不掉，旁注去「先不排班」。
- 欢迎页最后一页换成班次表单；故事页保留。先不排班仍要留下时刻，供以后手动计时使用。
- 已 onboarding 的用户不重跑欢迎页。
- 计时首页英雄卡、草稿、应用配置、配置态从三个壳删除。

### P2 — 计时态

按 surfaces 文档实现五态（含未排班）与穿插，而不是旧的七职能。

- 上班倒计时：通栏提前上班 + 分享；进度与休息日连续。
- 下班倒计时：午休 / 加班不切职能页；提前下班二次确认。
- 结算：无返回；加班可「其实还没走」；撤销提前下班仅限结束日当天。
- 休息：弱倒数 + 本周 / 本年 + 手动计时；不要「接下来」。
- 未排班：每天手动计时；次日零点回到询问。
- 有排班的手动计时：进班后横幅取消，回到休息，不写「上过班」。
- 规则错误横幅，不停表。
- 日历缝对齐小组件（含夜班结束落在的日历日）。

### P3 — 分享与外表面

- 分享文案 / 卡片数字 / 进度按态走（上班前不得用整班剩余说下班）。链接只带排班时刻，不含薪资与当日修正。
- 休息日、未排班开始前无分享。
- Widget：休息 `widgetRestDay` 缝、提前下班 `.done` /「今日已下班」不是休息日。
- Live Activity：结算与提前下班结束活动；休息日不装成工作中。
- 通知：提前下班后丢掉仍属于本班的提醒（现有 `shouldDeliverReminder` 方向保留并补测试）。

### P4 — 测试、文案、送审候选

- `OffWorkStoreTests` 按新口径改：删除「dismiss 回配置仍武装」这类断言；补提前上班、手动计时取消、设置那问、至少一天工作日、分享口径。
- 所有用户可见新键写入全部 19 份 `public/locales/*/translation.json`。
- `npm run check:version`；Bump `CURRENT_PROJECT_VERSION` 后 Archive，走现有 Xcode Cloud / TestFlight。

## 验收场景（产品，不是实现清单）

1. 新用户走完欢迎页，计时页已经在倒计时（或未排班询问），不必再「应用配置」。
2. 老用户打开即进对应态，不重看欢迎页；改时刻只能去设置，并被询问是否覆盖今天。
3. 周一 08:00 是上班倒计时；提前上班后变成下班倒计时，开始为现在、17:00 不变。
4. 没有「其实这时才开始」；10:00 打开仍从排班开始点算，应用不说迟到。
5. 午休时屏幕和分享都数回来，不切独立午休职能页。
6. 15:00 提前下班进入结算；撤销仅当天有效；「返回」不存在；周六是休息不是庆祝周五。
7. 结算后再加班，提前下班记录消失，钟继续走。
8. 周六好好休息 + 弱倒数到周一上班；手动计时可取消回休息；Widget 文案与日历缝一致。
9. 先不排班每天问；开始一次后次日零点再问。
10. 设置里把 17:00 改成 18:00，取消则今天和底图都不变；「只从下一班」则今天仍 17:00；「今天也改」今天与以后都是 18:00，且清掉当天修正。
11. 勾不掉最后一个工作日；切先不排班仍要问今天。
12. 分享：上班前说距上班；链接仍是排班时刻；图和链接无薪资。
13. 规则包缺失时能看到错误，排班不会被停掉，周末 Widget 不会因此改成「好好休息」直到重新开始。

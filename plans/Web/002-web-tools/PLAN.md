## 当前实现状态

经本机构建与浏览器验收，8 个 CN/US 工资页和两个语言目录已可在 `WEB_TOOLS_PREVIEW=1` 下构建预览。页面为 `/zh-CN/salary/cn`、`/zh-CN/salary/cn/monthly-to-daily`、`/zh-CN/salary/cn/monthly-to-hourly`、`/zh-CN/salary/cn/workdays-21-75`、`/en/salary/us`、`/en/salary/us/hourly-to-annual`、`/en/salary/us/annual-to-hourly`、`/en/salary/us/biweekly-paycheck`；目录为 `/zh-CN/tools` 与 `/en/tools`。它们仍是草稿，不能据此称作生产页面、已审核内容或已公开地区规则。所有工资页均待人工内容审核；中国大陆 21.75 参考口径的官方来源由主 Agent 报告已于 2026-10-31 在政府网站核对，其他市场规则没有据此视为已审核。

生产注册表和正式发布列表只收录 `published` 条目。预览草稿不得进入生产导航、sitemap、公开 alternate 或其他公开页面目录；切换预览标记不能代替语言、内容或地区规则审核。

现有 `/{lang}/work-hours-calculator` 已支持 19 种界面语言并属于已发布的通用工具。它不等于本项目的工资目录、工资换算页面或地区法规覆盖，也不能证明用户语言就是雇佣市场。新建的 `/en/tools` 与 `/zh-CN/tools` 目录当前同样只是预览草稿。

## 状态约定

- `existing-published`：本仓已有线上工具；只表示该工具路径/语言存在。
- `preview-draft`：仅预览构建可见，尚未通过生产发布门槛。
- `pending-review`：需要人工语言、内容或规则适用范围审查。
- `not-started`：尚无已交付能力；不代表用户需求为零。
- `unavailable` / `pending`：当前拿不到数据；不代表该指标为零。
- `unassigned`：尚未明确责任人；不虚构负责人、所有者或日期。

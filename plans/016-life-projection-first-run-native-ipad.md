# 016 · 人生选择、收入递减、首次恢复与原生 iPad 导航

状态：IMPLEMENTED / DEVICE ACCEPTANCE PENDING。2026-09-06 用户确认覆盖旧计划中相冲突的行为。

## 用户确认

- 人生“工作·已走过 / 工作·未来推算”必须能够稳定选中，粗略与多段精确职业经历一致。
- 未来收入新增“保持当前收入 / 逐步递减”。递减由起始年龄与退休时收入比例决定，按直线变化。45 岁 / 60% 仅为可编辑示例，必须保存才生效；旧档案不自动改为递减。
- 历史收入与已填写职业经历保持原值，空档不计收入。递减只作用于未来的当前薪资；如果所选起始年龄已经过去，从今天的当前薪资重新锚定，避免立即扣减一次。月薪 / 年薪与闰年、退休边界由共享 TypeScript 处理。
- 欢迎页配置任何班次和偏好前先检查已有 iCloud 数据，同时自动读取 StoreKit 权益。不能把查询失败等同于没有数据，不能把欢迎页默认值作为更新的云端设置上传。
- iPad 参考“文件”的导航方式：侧栏沿左侧进出，顶部玻璃 Tab 沿顶部进出。侧栏收起按钮旁显示 Logo / DoneAt，选项下恢复班次倒计时。删除负边距补偿；不承诺复刻系统应用的私有实现。

## 实施边界

- 生涯阶段 ID 来源于未切分的职业阶段身份，显示区间可随时间更新而不改变选中身份。
- iPad 使用 `NavigationSplitView(.balanced)` 管理侧栏，顶部玻璃导航独立使用顶部移动过渡，避免自适应 Tab 的形变飞移动效；三个入口保留各自导航路径。iPhone 壳保持既有形式。
- 首次云端检查独立于本机同步开关，只读当前账号 / generation / 当前 zone 的完整分页数据；不创建 zone，不上传默认设置。
- 下载在候选归档中处理，完整校验后原子提交。用户选择云设置时，已有本机偏好保留为可恢复的冲突副本；不同 generation 下存在本机未同步记录时暂停，不静默抹除。
- 恢复已有数据不要求重新购买；持续同步仍需 Plus。自动权益查询只用 StoreKit 当前权益；`AppStore.sync` 保留给明确的“恢复购买”操作。
- 未完成欢迎配置前不生成 dirty 同步偏好。离线继续的设备记录为未配对；以后开启或恢复同步时先提供云端选择。
- 正常同步引擎也先完成拉取，再允许上传；同步开关已开启不再等同于首次数据已恢复。
